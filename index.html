Chưa có nội dung nào.

Chế độ miễn phí dịch bằng Google Translate trong Apps Script của bạn — không tốn API. Câu nào cần chính xác hơn, bấm nút ◈ bên trái câu đó để Gemini dịch lại.

Cài đặt

API key Gemini nằm trong Apps Script thuộc tài khoản Google của bạn. Trang web này không nhận, không lưu và không gửi key đi đâu.

Model Gemini

Chỉ áp dụng khi dịch bằng Gemini. Đơn giá tính trên 1 triệu token — vào : nhập, ra : kết quả.

Bấm “Tải lại danh sách” để xem model mà API key của bạn dùng được.

Dịch nháp khi đang nói — mỗi 1,2 giây

Cách cài Apps Script
  1. Lấy Gemini API key tại aistudio.google.com/apikey — chỉ cần nếu bạn muốn dùng Gemini. Chế độ miễn phí không cần key.
  2. Tạo script mới tại script.new
  3. Dán toàn bộ nội dung file gas/Code.gs vào editor
  4. Mở ⚙ Project Settings → Script Properties → Add script property, đặt tên GEMINI_API_KEY và dán key vào ô Value, bấm Save
  5. Quay lại Editor, chọn hàm setup rồi bấm Run
  6. Deploy → New deployment → Web app
    Execute as: Me · Who has access: Anyone
  7. Chạy showSetup() rồi copy URL và token vào ô trên
Cần biết trước khi dùng
  • Nội dung cuộc họp được gửi tới Google — chế độ miễn phí qua Google Translate, chế độ Gemini qua Gemini API. Không dùng cho họp có thông tin mật.
  • Chế độ micro gửi âm thanh tới dịch vụ nhận dạng của Google qua Web Speech API của Chrome, không đi qua Apps Script của bạn.
  • Chế độ miễn phí dùng hạn mức Google Translate của Apps Script, khoảng 5.000 lượt/ngày với tài khoản Gmail thường.
  • Mỗi lượt gọi Gemini phát sinh chi phí theo biểu giá Gemini. Nên đặt hạn mức chi tiêu trong Google Cloud Console.
  • Đơn giá trong bảng model là số chép tay, không phải giá lấy trực tiếp từ Google — Google không có API giá. Kiểm tra lại tại trang biểu giá trước khi tin con số ước tính.
  • Token lưu trong bộ nhớ trình duyệt. Người dùng chung máy có thể đọc được. Nghi ngờ lộ thì chạy rotateToken().
  • Chia sẻ âm thanh tab chỉ chạy trên Chrome/Edge máy tính, không chạy trên điện thoại.
