Chưa có nội dung nào.

Nội dung nghe được sẽ được gửi tới Google Gemini để dịch.

Kết nối Apps Script

API key Gemini nằm trong Apps Script thuộc tài khoản Google của bạn. Trang web này không nhận, không lưu và không gửi key đi đâu.

  1. Lấy Gemini API key tại aistudio.google.com/apikey
  2. Tạo script mới tại script.new
  3. Dán toàn bộ nội dung file gas/Code.gs vào editor
  4. Dán key vào hàm setup() ở đầu file rồi bấm Run
  5. Deploy → New deployment → Web app
    Execute as: Me · Who has access: Anyone
  6. Chạy showSetup() rồi copy URL và token vào ô dưới đây
Dịch nháp khi đang nói — mỗi 1,2 giây

Cần biết trước khi dùng
  • Nội dung cuộc họp được gửi tới Google Gemini để nhận dạng và dịch. Không dùng cho họp có thông tin mật.
  • Token lưu trong bộ nhớ trình duyệt. Người dùng chung máy có thể đọc được. Nghi ngờ lộ thì chạy rotateToken().
  • Mỗi câu là một lời gọi API và phát sinh chi phí theo biểu giá Gemini. Nên đặt hạn mức chi tiêu trong Google Cloud Console.
  • Gói miễn phí giới hạn theo phút — họp dài liên tục có thể bị tạm dừng.
  • Chia sẻ âm thanh tab chỉ chạy trên Chrome/Edge máy tính, không chạy trên điện thoại.
